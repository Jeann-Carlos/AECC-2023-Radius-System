Our Services

AECC provides academic and network utility systems to members and computer science undergraduates.

Private Member Intranet

Secure, ad-free student wireless network utilizing RADIUS/Pi-hole directory configuration. Prevents external trackers and sandbox-blocks unauthenticated nodes.

Deploy web apps, API prototypes, or database schemas directly on our student-run server arrays. Available for project courses and hackathons.
